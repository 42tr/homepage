制作简历的方式：word 文档、markdown、latex、html。
- word 文档

  word 文档是最常用的方式，但是需要手动调整格式，比较麻烦。

- markdown

  markdown 是一种轻量级的文本格式，可以借助工具生成 html。markdown 的语法比较简单，可以参考 [markdown 语法](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet)。

- latex

  latex 是一种公式编辑工具，可以借助工具生成 html。latex 的语法比较复杂，可以参考 [latex 语法](https://zh.wikipedia.org/wiki/LaTeX)。latex 可以使用 [overleaf](https://www.overleaf.com/) 进行编辑，里面有很多模板可以使用。但是想要自己定制的话还是要熟悉 latex 语法，很不方便。

- html

  作为 web 全栈，html 自然不用多说，写好后通过网页打印成 pdf 即可。注意去掉页眉和页脚，显示背景图像。[源码参考](https://github.com/42tr/42tr.github.io/blob/42tr/src/pages/resumeZh/resumeZh.vue)
